# Resume Cheat Sheet: DevOps Engineer

> **How to translate this project into a 6-figure Resume.**

## Experience Bullet Points

### Cloud & Infrastructure (AWS + Terraform)
*   "Architected a highly available AWS environment (VPC, Multi-AZ) using **Terraform** modules, reducing environment provisioning time by **90%**."
*   "Implemented state locking with **DynamoDB** and remote state management with **S3** to ensure team collaboration safety."
*   "Designed secure network topology with public/private subnets and chained **Security Groups**, strictly adhering to least-privilege access."

### Containerization & Orchestration (Docker + Kubernetes)
*   "Containerized legacy Python applications using **Docker** multi-stage builds, reducing image size by **60%** and vulnerability surface area."
*   "Orchestrated microservices on **Kubernetes (EKS)**, ensuring zero-downtime deployments via **Rolling Updates** and Liveness/Readiness probes."
*   "Managed application configuration using **ConfigMaps** and **Secrets**, decoupling code from environment-specific configuration (12-Factor App)."

### CI/CD & Automation (GitHub Actions + Ansible)
*   "Built end-to-end **CI/CD pipelines** using **GitHub Actions**, integrating automated Unit Tests, Linting, and Docker builds."
*   "Integrated **Trivy** vulnerability scanning into the CI pipeline, blocking critical security issues from reaching production (Shift-Left Security)."
*   "Automated server hardening and patch management using **Ansible** playbooks, ensuring compliance with internal security policies."

### Observability & Operations (CloudWatch + Incident Management)
*   "Designed **CloudWatch Dashboards** to monitor 4 Golden Signals (Latency, Traffic, Errors, Saturation), improving incident response time."
*   "Implemented automated alarms for High CPU and Error Rates, reducing Mean Time to Detect (MTTD) to under **2 minutes**."
*   "Led **Post-Mortem (RCA)** processes for production incidents, utilizing the '5 Whys' technique to drive systemic improvements."

## Skills to Highlight
**Languages:** Python, HCL (Terraform), YAML (Ansible/K8s), Bash.
**Tools:** Docker, Kubernetes, GitHub Actions, AWS CLI.
**Concepts:** GitFlow, Immutable Infrastructure, 12-Factor App, DevSecOps.
